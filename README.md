# Little Chef

A cooking game for kids ages 3 to 6. Pick a treat (cupcakes, pancakes, pizza or cookies), count ingredients into the bowl, stir, mix colors, find letters, bake, decorate, and take bites. Every instruction is spoken, so no reading is needed.

- Plain HTML/CSS/JS, no build step. Works offline and installs as an app (PWA) on Android, iPhone/iPad, Windows, Mac and Linux.
- Grown-ups menu: press and hold the gear on the home screen. Set the age level (3–4 or 5–6), voice, voice pitch, and sounds.
- Bump `VERSION` in `sw.js` (and in `js/app.js`) on every change so installed copies update.
- Font: Fredoka (SIL Open Font License, see `fonts/OFL.txt`). All artwork is original SVG.
